# 流域水库调度指标预计算与看板治理工具

面向防汛值班室的纯前端（React + TypeScript + WebWorker + IndexedDB）工具。所有数据保存在浏览器
IndexedDB 内，运行时不依赖后端；水位→蓄水换算、水量平衡、三类调度指标全部由可复算的纯函数引擎产出，
看板/图表/明细/简报/复盘只能读取**同一次锁定运行**的结果，不允许各页面直接读取“最新文件”。

## 1. 核心计算口径（与页面实现一一对应）

### 1.1 水量平衡方程（`src/lib/balance.ts`）

对每个固定时间网格区间 [t1, t2]：

```
R = S(t2) − S(t1) − [ ∫Q入dt − ∫Q出dt + P×A − 蒸发×A + 调入量 − 调出量 ]
```

- 流量积分（`src/lib/integrate.ts`）：相邻读数**实际区间秒数**梯形积分；区间两端缺读数、存在显式
  缺失/作废记录、量纲不相容、采样间隔 > 1.5×名义步长（断面故障）均判覆盖不足，**不以零补齐**。
- 水位→蓄水（`src/lib/curves.ts`）：按采样时刻**当时有效且已审批**的库容曲线线性插值，超曲线范围
  不外推；区间两端曲线版本不同则在事实上标记 `curveSwitched`。
- 雨量/蒸发（`src/lib/rainfall.ts`）：分区雨量按水库面雨量权重加权，再乘以区间中点有效库面面积
  折算水量；重叠雨量**按修订关系替代而非累加**，无修订关系的重叠直接判不可闭合。
- 跨库调水：该水库从无此类业务读数时按 0 计且闭合；一旦存在调水业务，某时段缺测仍判覆盖不足。
- 残差超测量容差（`max(绝对容差, 比例容差×量级)`）时，事实列出**未闭合来源**，绝不把差额塞入“损耗”。

### 1.2 三类指标（`src/lib/indicators.ts`，同一运行一次发布）

1. **防洪余量** = 规则汛限库容 − 已确认蓄水量；规则重叠/缺失或蓄水不可确认时为待核。
2. **近期来水压力** = 指定窗口内可确认净入库量 / 防洪余量，同时给出由各平衡项不确定度合成的
   **未知范围**与压力比区间；窗口内任一区间不可确认则指标待核。
3. **泄洪空间** = 当前净入库范围（含未知量）延续至下一决策时点时，回到规则目标库容所需的出库
   流量范围，并计算与下游允许泄流范围的**差额**（正值表示允许泄流不足）。

### 1.3 规则曲线穿越与敏感区间（`src/lib/crossings.ts`）

预警从蓝色升级为橙色时，规则曲线与下游安全流量都会改变。越线分析强调“某段水位/流量何时穿越哪条规则线”，
而不是把当前等级倒灌解释历史运行：

- **规则目录**保存流域、预警级别、生效区间、曲线点与审批状态；可限定水库或作为流域级规则。曲线语义分为
  `linear`（曲线点线性插值）与 `step`（保持前值、曲线点处跃变），并记录该等级对应的下游安全流量范围。
- **指标运行**在锁定快照时冻结预警规则曲线，并把每个参与水库的连续水位、入库/出库流量序列（`ObservedSeries`）
  落库，越线分析直接复用该运行序列，不读取“最新文件”。
- **两种判定模式**：
  - `interpolated`：规则（按 linear/step 语义）与观测都视为连续，在相邻观测与规则曲线点之间求
    `g(t)=观测(t)−阈值(t)` 的交点，给出穿越**点时刻**；
  - `grid`：只在观测时间格上判断规则关系，穿越时刻表示为 `[前观测, 后观测]` **区间**，语义保守、可回查。
  两者都计算规则触发范围；模式建议综合观测中位间隔、规则曲线连续性与闸门操作量，不由实现预设插值更正确。
- 每条规则输出：首次越线（时刻/区间、前后证据、精度声明）、高于阈值持续时长（确认值与上限）、
  峰值越线幅度、接近阈值时间带，以及插值可信性 caveat（低频观测、闸门操作、含可疑读数、阶梯曲线等）。
- 若穿越由规则阈值阶跃造成，标注 `threshold_step` 与阶跃前后阈值，与观测变化造成的穿越分开；
  线性规则曲线的连续移动标注 `threshold_trend`。
- **规则有效期重叠不自动选取**：同等级多条已审批规则重叠时拒绝求解并要求显式绑定；并发草案在目录中分别保留，
  分析必须分别绑定。
- **发布冻结**：发布分析记录时深拷贝观测序列与规则引用。规则审批撤回、曲线点修改或版本变化后，已发布记录
  保留当时引用；`bindingDrift` 列出目录漂移，新比较需另建版本/重新绑定。
- **情景比较与归因**：同一模式下对比两套规则（如蓝→橙）或两个观测变体（base/strict）。通过反事实替换
  （B 的观测套 A 的规则 / A 的观测套 B 的规则）区分差异来自 `fact_change`（事实变化）还是
  `threshold_definition`（阈值定义），同时不同时为 `mixed`；不同模式之间不可直接相减，只并排核对精度。
- **等级切换不回溯改写历史**：越线结论只比较观测与当时绑定的规则；当前等级不会倒灌生成历史越线记录。

### 1.4 运行锁定与两种物化设计

- 每次运行固定：资料截止点（`receivedAt <= cutoff` 才纳入快照，迟到雨量被确定性排除）、曲线版本、
  规则版本、预警规则曲线、容差、时间网格，形成不可变 `RunSnapshot`。
- **物化设计**：WebWorker 预计算“水库—时段平衡事实”并落 IndexedDB，看板切换与相邻区间残差比对快；
  **按需设计**：只保留快照与积分计划，下钻时在 Worker 内用**同一引擎、同一版本与容差**即时求值。
  设计建议（`adviseDesign`）依据文件规模、值班响应时限与复盘粒度自动给出。

## 2. 本地启动

要求 Node 22（本仓库在 Node 22.14 / npm 10.9 下验证）。

```bash
npm install --no-audit --no-fund
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建，http://localhost:4173
npm run test       # vitest 单元测试 + 端到端集成测试 + 渲染冒烟（共 45 个用例）
```

> 若本机 npm 缓存目录权限异常，可指定项目内缓存：
> `npm install --cache ./.npm-cache --no-audit --no-fund`

### Docker 一键启动

```bash
docker compose up --build
# 访问 http://localhost:8080 （nginx 托管 dist 静态产物，含 SPA 回退与健康检查）
```

## 3. 测试账号与使用流程

本工具为值班室本地单页应用，**无登录体系**；并发批注场景通过批注面板的“作者”下拉模拟两个值班
页面（值班员甲 / 值班员乙 / 防办值班长），无需任何账号密码。

标准验收流程：

1. 打开「资料接入」→ 点击 **播种内置演示数据集**（也可用「导入 CSV」上传 `samples/sample-readings.csv`）。
2. 打开「平衡运行台」→ 选择截止点预设：
   - `RUN1 06:30`：08:00 才补传的迟到雨量被排除；
   - `RUN2 09:30`：迟到雨量已纳入。
   点击“锁定快照并在 WebWorker 中运行”，完成后“选为看板运行”。
3. 「调度看板」查看地图、KPI、过程图表、指标明细与值班简报（全部同源同运行）。
4. 「规则越线分析」选择该运行 → 水库 → 指标（水位/入库/出库）→ 绑定规则（蓝色、橙色或并发草案 A/B），
   切换 `连续插值` 与 `观测格判定`，对比情景并查看归因，最后发布冻结记录。可复现顺序：
   青溪河/水位/`base` → 绑 A=QX-LV-BLUE-2026、勾选 B=QX-LV-ORANGE-2026 → 同模式查看“阈值定义”归因与下游安全流量差
   → 发布；再点“模拟：撤回情景A规则的审批”，已发布记录仍显示冻结时的 approved，漂移提示另有条目。
   白沙河/入库流量 → 绑 BS-FLOW-ORANGE-2026 看 03:00 阈值阶跃；西岭/水位看低频与重叠。
5. 「复盘回查」从风险结论下钻到参与区间、换算曲线版本、六个平衡项与原始读数证据，并做字段级批注。
6. 「曲线与规则目录 → 预警规则曲线」查看流域/等级/有效期/曲线点/审批，以及重叠与并发草案治理检查。

## 4. 内置验收样例

| 场景 | 数据位置 | 预期表现 |
| --- | --- | --- |
| 迟到雨量 | z2 分区 05~06 时次 08:00 接收 | RUN1 青溪河 05~06 区间覆盖率不足不可闭合；RUN2 同区间闭合 |
| 跨库调水 | 青溪河调入 20 m³/s、白沙河调出 10 m³/s | 平衡项以正确符号计入，集成测试校验水量 = 流量×3600s |
| 库容曲线切换 | 白沙河 03:00 起 BS-S-2019→BS-S-2026 | 事实标记换版并保留 t1/t2 两个曲线 ID |
| 断面故障 | 白沙河 04:00 入库流量显式缺失 | 03~04 区间残差为 null、指标待核，缺失不补零 |
| 并发批注 | 复盘页两个作者同时编辑 | 不同字段各自保留；同字段冲突较新者胜并留痕，无整单覆盖 |
| 大文件下钻 | 东风水库 5 天 10 分钟级流量（每序列 721 点，入库+出库共约 1442 条） | 120 个小时区间全部闭合，证据链每区间 20+ 条原始读数 |
| 等级切换（蓝→橙） | 青溪河 06 时前水位 105.0→106.75；蓝 105.6 / 橙 106.4，下游安全流量 [40,120] / [30,90] | 同一观测下蓝先越线、橙后越线；差异归因为阈值定义，下游安全流量差 −10/−30 |
| 阶梯规则曲线 | 白沙河阶梯规则 03:00 阈值 85→75，含 03:00 闸门调度令 | 03:00 越线 `inducedBy=threshold_step`；窗口含闸门操作，声明插值可信性受限，模式建议 grid |
| 低频水位 | 西岭人工水尺 3 小时/次 | 建议观测格模式；连续插值给出点时刻但带“低频”caveat；网格给出 [03:00,06:00] 区间 |
| 规则重叠 | 西岭 XL-LV-A / XL-LV-B 同等级已审批且适用期重叠 | 候选组标记重叠、不自动选取；同时绑定两规则拒绝求解；各草案/版本分别绑定 |
| 并发草案 | 青溪河橙级草案 A（106.2）/ B（106.6） | 目录分别保留；分别绑定得到不同首次越线；发布 A 的记录状态为“绑定草案（演练）” |
| 审批撤回 | 橙色规则 approved→retired 且曲线点 +0.4 | 已发布记录保留冻结引用（approved、106.4）；`bindingDrift` 列出状态与曲线点漂移 |

另含：雨量修订替代（01~02 时次 8mm 被 12mm 修订，不累加为 20mm）、青溪河 02:00 可疑水位制造
+50,000 m³ 超差残差（未闭合原因列明且无“损耗”项）、西岭草稿库容曲线 + 规则适用期重叠导致全指标待核。

## 5. 已执行的验证（实际结果）

以下命令均在交付环境实际执行通过：

- `npm run build`（`tsc -b` 严格类型检查 + Vite 生产构建）：通过，Worker 独立分包
  `dist/assets/balance.worker-*.js`。
- `npm run test`：**4 个测试文件、45 个用例全部通过**，覆盖曲线插值/无效与重叠、流量积分与断面故障、
  雨量修订替代、六类端到端场景、字段级并发批注（fake-indexeddb 复刻 Worker 落库路径），以及越线分析的
  等级切换、阶梯曲线、低频观测、敏感时间带、规则重叠、并发草案、审批撤回/冻结与事实 vs 阈值归因（15 个纯函数用例 +
  2 个端到端落库用例 + 4 个服务端渲染冒烟用例）。
- 生产构建 HTTP 冒烟（`vite preview`）：`/`、`/crossing`（SPA 回退）、主 JS chunk、Worker chunk、CSS 均返回 200；
  开发服务器（`npm run dev`）对 `/` 与 `/src/pages/CrossingPage.tsx` 返回 200。
- 浏览器端 E2E 未在本容器执行：容器缺少 Chromium 运行库（libatk 等）且无 root 权限安装，Chromium 启动即崩溃。
  因此界面以服务端渲染冒烟（结果卡/比较卡/不可比提示）与上述 HTTP 冒烟替代，业务结论由 45 个用例覆盖。

## 6. 目录结构

```
src/
  types.ts                  领域类型（读数/曲线/规则/运行/事实/指标/批注）
  db.ts                     IndexedDB 存储（v2 新增规则曲线/序列/越线分析）、修订关系、字段级批注合并
  lib/
    crossings.ts            规则曲线穿越/敏感区间：插值与网格两种语义、情景比较与归因
    crossings.test.ts       越线分析纯函数测试（15 用例）
    render.test.ts          无浏览器渲染冒烟（引导页/结果卡/比较卡/不可比提示）
    curves.ts               曲线版本选择与线性插值（不外推）
    integrate.ts            实际秒数梯形积分与覆盖度/量纲检查
    rainfall.ts             修订去重、分区权重、雨量/蒸发折算
    balance.ts              固定网格平衡事实物化（纯函数引擎）
    indicators.ts           防洪余量/来水压力/泄洪空间指标
    engine.test.ts           纯函数引擎单元测试（17 用例）
    integration.test.ts      fake-indexeddb 端到端集成测试（9 用例，含越线冻结/撤回 2 例）
  workers/balance.worker.ts WebWorker：物化落库 + 按需即时求值
  services/                 运行编排、CSV 接入与播种、连续观测序列落库
  pages/                    资料接入、目录治理、运行台、看板、规则越线分析、复盘
  components/               地图、图表、简报、状态徽标、字段级批注面板
samples/sample-readings.csv CSV 接入样例（含迟到/缺失/可疑/调水/蒸发）
```
